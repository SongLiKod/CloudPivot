# 云枢 CloudPivot 产品需求文档 PRD‑V1.1
文档版本：V1.1
编制日期：2026‑09‑07
适配平台：Windows、Android
更新说明：增加主题跟随系统/浅色/深色三模式；浅色主色调白色+生态绿

## 1 文档概述
### 1.1 文档目的
云枢 CloudPivot 是面向站长、运维人员的本地私有化客户端工具，解决多Cloudflare账号管理繁琐，需要频繁切换浏览器后台的痛点。软件内部完成域名、DNS、Workers、Pages、WAF安全规则运维，无需跳转Cloudflare官网。支持Windows桌面、Android移动端；支持跟随系统、浅色、深色三种外观模式。本文档作为产品、开发、测试的需求对齐与验收依据。

### 1.2 适用范围
产品设计、前端开发、功能测试、项目验收。
本软件为纯本地客户端，无自建后端服务，仅调用 Cloudflare V4 开放API。

### 1.3 术语定义
- CF账号：独立Cloudflare账号，支持API Token / Global Key鉴权
- 批量运维：跨多个CF账号批量执行配置操作
- 跟随系统主题：读取操作系统外观自动切换浅色/深色
- AES‑256‑GCM：账号密钥本地加密存储算法

## 2 项目背景与业务痛点
1. 多个Cloudflare账号需要反复切换浏览器登录，运维效率低下。
2. 域名、DNS、Workers、Pages、WAF全部依赖网页后台，缺少客户端一体化操作。
3. 多账号资源分散，缺少统一总览，缺少批量配置、批量同步能力。
4. 现有工具功能零散，缺少移动端支持，深浅主题适配不完善。

## 3 产品目标
1. 单客户端统一管理多个Cloudflare账号，无需浏览器切换账号。
2. 全部运维操作软件内闭环，不跳转Cloudflare官网。
3. 支持单账号精细操作 + 跨账号批量运维。
4. 外观三模式：跟随系统 / 浅色模式（白+生态绿） / 深色模式，切换即时生效。
5. 同时支持 Windows、Android 双端。
6. API密钥本地加密保存，绝不上传第三方服务器。

## 4 运行环境与目标用户
### 4.1 目标用户
站长、网络运维、工作室，同时维护多个Cloudflare账号。

### 4.2 支持平台
1. Windows：Windows10 / Windows11（32位、64位）
2. Android：Android10 ~ Android14，手机、平板自适应
> 暂不支持 Mac、iOS、Linux

## 5 UI主题规范
### 5.1 主题模式（设置页面）
1. **跟随系统（默认）**：读取系统外观自动切换浅色/深色
2. **强制浅色模式**：白底，生态绿为主色调
3. **强制深色模式**：深色背景，绿色作为强调色

> 切换无需重启软件，配置持久化本地存储；图表、代码编辑器、弹窗、表单全部自动适配主题。

### 5.2 浅色模式色值
- 主色生态绿：`#22C55E`
- 辅助绿：`#16A34A`、`#86EFAC`
- 页面背景：`#FFFFFF`
- 卡片背景：`#F9FAFB`
- 主文字：`#1F2937`
- 次要文字：`#6B7280`
- 成功：`#22C55E`；警告：`#F59E0B`；错误：`#EF4444`

### 5.3 深色模式色值
- 主强调绿：`#22C55E`
- 辅助绿：`#4ADE80`
- 页面背景：`#111827`
- 卡片背景：`#1F2937`
- 主文字：`#F9FAFB`
- 次要文字：`#9CA3AF`
- 成功：`#4ADE80`；警告：`#FBBF24`；错误：`#F87171`

### 5.4 状态统一标识
在线=绿色；离线=灰色；异常=红色；警告=黄色

## 6 功能需求
### 模块1 账号鉴权与分组管理
1. 新增账号：支持API Token、邮箱+Global Key；新增时校验连通性与权限；支持自定义账号名称、备注、标签；密钥AES‑256‑GCM加密存储；识别账号状态：正常 / 失效 / 权限不足 / 过期。
2. 批量账号：Excel模板批量导入账号；批量检测账号存活；批量刷新资源；批量删除失效账号。
3. 账号分组：自定义分组；账号拖拽、批量移入分组；分组筛选、关键词搜索、账号置顶；分组折叠展开。
4. 数据同步：可配置定时同步周期：1/5/10/30分钟；一键刷新全部账号；支持单账号单独刷新。

### 模块2 全局仪表盘首页
1. 统计概览：账号总数、正常账号、异常账号；域名总数、Workers总数、Pages项目总数；今日请求量、流量、缓存命中率、拦截攻击数量。
2. 可视化图表：流量趋势图、请求量趋势图、资源占比饼图；图表自动适配深浅主题。
3. 快捷操作入口：新增账号、新建Workers、新建Pages、DNS批量操作、系统备份。

### 模块3 域名 & DNS解析管理
1. 域名总览：聚合全部账号域名列表；支持按账号、代理状态、过期时间筛选；关键词搜索定位域名。
2. 域名操作：启用、暂停、解锁、删除域名；查看域名详情：注册时间、过期时间、NS记录、证书状态。
3. DNS解析管理：支持A、AAAA、CNAME、MX、TXT、SRV、CAA记录；增删改解析记录；自定义TTL；开关CDN代理；单域名DNS配置复制。
4. 批量DNS运维：跨账号批量新增解析；批量修改TTL、开关代理；批量删除解析；DNS配置模板一键同步到多账号。

### 模块4 Cloudflare Workers管理
1. Workers列表：聚合全部账号Workers；展示脚本名称、绑定路由、运行状态、请求量、CPU配额。
2. 单脚本运维：新建空白Worker；内置代码编辑器，语法高亮、自动缩进、语法报错提示；保存、部署脚本；版本记录、历史版本回滚。
3. 环境与触发器：普通变量、加密密钥变量管理；路由规则配置；运行内存调整、Cron定时触发器配置。
4. 批量运维：跨账号批量部署代码；批量同步环境变量；批量启停路由；批量删除脚本。

### 模块5 Cloudflare Pages管理
1. Pages总览：聚合全部账号Pages项目；展示项目名称、绑定域名、构建状态、部署时间、关联仓库信息。
2. 项目创建：新建空白Pages项目；绑定GitHub/Gitee仓库；配置构建命令、输出目录、环境参数。
3. 项目运维：在线修改项目配置；手动触发重新构建；查看实时构建日志、错误日志；开启/关闭自动部署；绑定自定义域名、查看证书状态。
4. 批量操作：批量更新环境变量；批量触发重新构建；批量开关自动部署。

### 模块6 WAF安全规则管理
1. 多账号WAF规则查看、新增、编辑、删除。
2. IP黑白名单批量导入导出。
3. 速率限制、地区访问限制配置。
4. 拦截/放行规则跨账号同步。

### 模块7 批量跨账号运维
1. 多数单账号操作支持跨多账号批量执行。
2. 批量任务队列面板：展示任务进度，支持暂停、终止任务。
3. 批量任务独立日志留存。

### 模块8 备份还原 & 自动巡检
1. 全账号配置本地加密备份、备份文件还原。
2. 定时自动巡检：DNS异常、配额超限、账号失效检测。
3. 异常弹窗提醒，写入系统操作日志。

### 模块9 日志审计 & 数据报表
1. 全量操作留痕：操作时间、目标账号、操作内容、执行结果。
2. 日志检索、条件筛选、日志导出。
3. 支持导出Excel / PDF报表；配额用量统计报表。

### 模块10 双端差异化功能
#### Windows端专属
1. 窗口大小缩放、最小化、托盘后台常驻。
2. 全局快捷键支持。
3. 鼠标右键菜单。
4. 高分屏1080P / 2K /4K适配。

#### Android端专属
1. 横竖屏布局自适应。
2. 下拉手势刷新数据。
3. 触控按钮尺寸≥44px，符合安卓交互规范。
4. 后台保活执行定时同步。
5. 离线缓存，无网络可查看历史缓存数据。

### 模块11 系统设置
1. 外观主题设置：跟随系统 / 浅色模式 / 深色模式。
2. 数据自动同步周期配置。
3. Windows可自定义备份文件存储路径。
4. 日志保留时长配置。
5. 版本信息、关于页面。

## 7 非功能需求
### 7.1 安全性
1. API密钥使用AES‑256‑GCM加密本地存储，禁止明文持久化，不上传云端。
2. 全部请求调用Cloudflare官方V4 API，无破解行为。
3. 高危批量操作增加二次确认弹窗。
4. 操作日志不可篡改，支持问题溯源。

### 7.2 性能
1. 支持管理50个以上Cloudflare账号。
2. 批量任务后台异步执行，不阻塞UI界面。
3. 常规数据同步延迟控制在3秒以内。

### 7.3 兼容性
1. Windows：Win10、Win11；Android：Android10‑14。
2. 兼容Cloudflare免费账号与付费账号。

### 7.4 稳定性
1. API请求失败自动重试；单个账号异常不影响其他账号运行。
2. 后台定时任务稳定执行。

## 8 迭代排期
### 一期（首发版本）
1. 多账号加密绑定、分组、状态检测
2. 域名聚合、DNS增删改查
3. Workers新建、代码编辑、部署、变量配置
4. Pages基础搭建与配置修改
5. 完整三模式主题：跟随系统、浅色、深色
6. Windows + Android基础适配

### 二期迭代
1. 全部跨账号批量运维功能
2. WAF安全规则完整管理
3. 仪表盘可视化图表（深浅色适配）
4. 本地备份还原、自动巡检

### 三期迭代
1. 用户自定义定时自动化任务
2. 完整报表导出功能
3. 高级批量同步模板
4. 双端交互细节打磨优化

## 9 验收标准
1. 可正常绑定≥10个Cloudflare账号，鉴权校验正常。
2. 域名、DNS、Workers、Pages、WAF全部操作软件闭环，无需跳转官网。
3. 三种主题模式切换即时生效，编辑器、图表、弹窗样式适配正常。
4. 单账号、跨账号批量执行结果与Cloudflare后台完全一致。
5. API密钥密文存储，不存在明文泄露。
6. Windows、Android两端功能均可正常运行。
